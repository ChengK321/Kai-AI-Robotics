# Upstream Study

Source-code study of important robotics/embodied-AI repositories.

Initial targets:

```text
upstream-study/
├── nav2/
├── lerobot/
├── sobits-vla-tools/
├── kios/
├── isaac-lab/
└── README.md
```

Each target should eventually contain:
- repository overview and why it matters;
- architecture/call-flow notes;
- key source files to read;
- official demo reproduction notes;
- one meaningful code modification;
- integration ideas for our own systems.

Rule: `git clone + run demo` is only Level 1, not completion.
