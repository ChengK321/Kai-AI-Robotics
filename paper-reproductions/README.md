# Paper Reproductions

Reproduce a small number of milestone methods deeply rather than many papers superficially.

Initial candidates:

```text
paper-reproductions/
├── act/
├── diffusion-policy/
├── openvla-or-openpi/
├── groot-or-hy-vla/
└── README.md
```

Each reproduction should pass four levels:

1. Reproduce official result or benchmark.
2. Map paper modules to source code.
3. Run at least one ablation or controlled modification.
4. Migrate the method into our own robot system or evaluation suite.

Store configs, metrics, plots, failure cases, and conclusions so results remain comparable over time.
