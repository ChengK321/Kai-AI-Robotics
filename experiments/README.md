# Experiments

Small, controlled experiments that answer one concrete engineering question.

Examples:
- effect of dataset size on ACT success rate;
- action horizon vs. latency and stability;
- VLM prompt/observation changes for semantic navigation;
- recovery strategy comparisons;
- local vs. cloud inference latency.

Each experiment should record:
- question / hypothesis;
- environment and commit SHA;
- config;
- result;
- conclusion;
- whether it should change a system design.

Avoid dumping unstructured notebooks here.
